# RanPOS Print Agent (โปรแกรมพิมพ์เบื้องหลัง)

โปรแกรมเล็กๆ ที่รันอยู่เบื้องหลังบนคอม Windows ในร้าน รับงานพิมพ์จากคิวของ POS (`printJobs`)
แล้วส่งไปเครื่องพิมพ์ใบเสร็จที่ต่อ USB — **ไม่ต้องเปิดหน้า Print Station หรือเบราว์เซอร์ค้างไว้**
เปิดเองทุกครั้งที่เข้า Windows และ Windows เปิดใหม่ให้เองถ้าโปรแกรมหยุด

## ทำงานอย่างไร

```
แท็บเล็ต/มือถือหลายเครื่อง ──► คิว printJobs (Firestore) ──► Print Agent บนคอมร้าน ──► Windows ──► เครื่องพิมพ์ USB
  (พิมพ์ QR / คิดเงิน / ชำระเงิน)        (คิวและรูปแบบเดิม)         (จองงาน → พิมพ์ → รายงานผล)
```

- **คิวและรูปแบบเอกสารเดิม**: ใช้ `lines` + QR ที่ POS สร้างอยู่แล้ว (ใบ QR โต๊ะ, ใบแจ้งค่าอาหาร, ใบเสร็จ, ใบครัว)
  พิมพ์ผ่านไดรเวอร์ Windows ด้วย GDI+ ภาษาไทยใช้ฟอนต์ของ Windows (Tahoma/Leelawadee)
  ตั้งกระดาษและตัดกระดาษตามไดรเวอร์
- **ใบเสร็จอัตโนมัติ**: สร้างในทรานแซกชันเดียวกับการเปลี่ยนบิลเป็น "ชำระแล้ว" (`src/lib/pos/payOrder.ts`)
  — มีใบเสร็จก็ต่อเมื่อชำระสำเร็จ และได้ **ครั้งเดียวต่อการชำระ** แม้กดยืนยันซ้ำ/ส่งคำขอซ้ำ/สองเครื่องกดพร้อมกัน
  (id ของงานคงที่ `receipt-<orderId>`) การพิมพ์ซ้ำโดยตั้งใจ (ประวัติออเดอร์ / ปุ่ม "พิมพ์ใหม่") เป็นงานใหม่เสมอ
- **จองงานก่อนพิมพ์**: เปลี่ยน `pending → printing` ในทรานแซกชัน ถ้ามีสถานีอื่นจองไปแล้วจะไม่พิมพ์ซ้ำ
- **สถานะหลังพิมพ์**

  | สถานะ | ความหมาย |
  |---|---|
  | `pending` รอพิมพ์ | อยู่ในคิว (รวมถึงตอนคอมออฟไลน์/เครื่องพิมพ์หลุด — พิมพ์เองเมื่อพร้อม) |
  | `printing` กำลังพิมพ์ | ถูกจองโดยสถานีหนึ่ง |
  | `sent` ส่งเข้าเครื่องพิมพ์แล้ว | Windows รับงานและส่งถึงเครื่องพิมพ์ครบแล้ว — ไดรเวอร์ USB ยืนยันได้แค่นี้ **ไม่ได้ยืนยันว่ากระดาษออก** |
  | `uncertain` ไม่แน่ใจว่าออก | ส่งถึงเครื่องพิมพ์แล้ว (หรืออาจถึง) แต่เกิดปัญหา/ค้าง/โปรแกรมหยุดกลางคัน — **ไม่พิมพ์ซ้ำเอง** ให้พนักงานดูที่เครื่องก่อน |
  | `failed` | ไม่ได้พิมพ์แน่นอน |

  งานที่ `uncertain`/`failed`/ค้างนาน และ Print Agent ที่ออฟไลน์ จะขึ้นแถบแจ้งเตือนบนทุกหน้า POS
  พร้อมปุ่ม **พิมพ์ใหม่** (สร้างงานใหม่) และ **ออกแล้ว ไม่ต้องพิมพ์**
- **สิทธิ์จำกัด**: โปรแกรมล็อกอินด้วยรหัสของตัวเอง (custom token: `role=printAgent`, `shopId`, `stations`)
  Firestore rules ให้แตะได้แค่งานพิมพ์ของร้านและสถานีตัวเอง กับสถานะ heartbeat ของตัวเอง
  ไม่มีสิทธิ์อ่านออเดอร์ เมนู หรือข้อมูลอื่น ไม่มีกุญแจ admin อยู่บนคอมร้าน
  รหัสลับเก็บบนคอมแบบเข้ารหัส DPAPI (อ่านได้เฉพาะผู้ใช้ Windows คนนั้นบนคอมเครื่องนั้น)
  และยกเลิกได้จาก Admin

## ติดตั้ง (ทำครั้งเดียวต่อคอม)

ต้องมี: Windows 10/11, ติดตั้งไดรเวอร์เครื่องพิมพ์แล้ว และ "Print a test page" ของ Windows พิมพ์ออก

1. **Admin → ตั้งค่าร้าน → โปรแกรมพิมพ์เบื้องหลัง** ตั้งชื่อเครื่อง เลือกสถานี (แคชเชียร์/ครัว) → **เพิ่มโปรแกรมพิมพ์**
   จะได้ **คำสั่งติดตั้ง** และ **รหัสเชื่อมต่อ** (แสดงครั้งเดียว)
2. บนคอมที่ต่อเครื่องพิมพ์ (ล็อกอิน Windows ด้วยบัญชีที่ใช้ประจำ) คลิกขวา Start → **Windows PowerShell**
   วางคำสั่งติดตั้ง กด Enter
3. ถ้ายังไม่มี Node.js ตัวติดตั้งจะลงให้ผ่าน winget (ถ้าลงไม่ได้ ให้ลง Node.js LTS จาก nodejs.org แล้วรันคำสั่งเดิมใหม่)
4. วาง **รหัสเชื่อมต่อ** เมื่อถูกถาม
5. **เลือกเครื่องพิมพ์**: จะมีรายการเครื่องพิมพ์ใน Windows พร้อมเลข ใส่เลขของเครื่องใบเสร็จ
   (ระบบเดาเครื่องที่ชื่อมี XP/POS/80 ไว้ให้ กด Enter ได้เลยถ้าถูก)
6. ตัวติดตั้งพิมพ์ **ใบทดสอบ** ตอบ `y` ถ้าออกและภาษาไทยอ่านได้
7. เสร็จแล้วจะลงทะเบียน Task Scheduler ชื่อ **RanPOS Print Agent** (เริ่มเมื่อเข้า Windows, รีสตาร์ทเองทุก 1 นาทีถ้าหยุด)
   และเริ่มทำงานทันที ใน Admin สถานะจะเป็น **ออนไลน์** ภายใน 30 วินาที

ไม่ต้องใช้สิทธิ์ Administrator ไฟล์อยู่ที่ `%LOCALAPPDATA%\RanPOS\print-agent` (log อยู่ในโฟลเดอร์ `logs`)
ถ้า Task Scheduler ใช้ไม่ได้ ตัวติดตั้งจะใส่ shortcut ในโฟลเดอร์ Startup แทน

**ตั้งค่า Windows เพิ่มเติม**: ปิด Sleep (Settings → System → Power) และตั้งให้ Windows ล็อกอินอัตโนมัติ
ถ้าต้องการให้พิมพ์ได้ทันทีหลังเปิดคอมโดยไม่ต้องมีคนล็อกอิน

**เปลี่ยนเครื่องพิมพ์ / ย้ายคอม**: รันคำสั่งติดตั้งใหม่ (สร้างรหัสใหม่ได้) — ของเดิมถูกแทนที่
**ถอนการติดตั้ง**: `powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\RanPOS\print-agent\uninstall.ps1"`
แล้วกด **ยกเลิก** ที่ Admin

**อย่าเปิดหน้า Print Station ในเบราว์เซอร์ไปพร้อมกัน** (ไม่พิมพ์ซ้ำเพราะมีการจองงาน แต่จะแย่งงานกัน)

## เปิดใช้งานใน POS

Admin → ตั้งค่าร้าน → สถานีพิมพ์:
- **พิมพ์ใบแจ้งค่าอาหารที่แคชเชียร์** (ตอนกด "คิดเงิน")
- **พิมพ์ใบเสร็จอัตโนมัติหลังชำระเงิน**
- **พิมพ์ QR สั่งอาหารของโต๊ะ**

## ทดสอบหน้างาน (ทำตามลำดับ ใช้แท็บเล็ต 2 เครื่องขึ้นไป)

ก่อนเริ่ม: ปิดเบราว์เซอร์บนคอมร้านทั้งหมด ดูว่า Admin ขึ้น "ออนไลน์"

| # | ทำ | ต้องได้ |
|---|---|---|
| 1 | เครื่อง A กด **พิมพ์ QR** โต๊ะ 1 | ใบ QR ออกภายในไม่กี่วินาที สแกนแล้วเปิดหน้าสั่งของโต๊ะ 1 |
| 2 | เครื่อง A และ B กดพิมพ์ QR คนละโต๊ะพร้อมกัน | ออก 2 ใบ ไม่ซ้ำ ไม่หาย |
| 3 | เปิดบิล กด **คิดเงิน** | ใบแจ้งค่าอาหาร + QR พร้อมเพย์ยอดตรง |
| 4 | กด **ยืนยันชำระ** | ใบเสร็จออก 1 ใบ |
| 5 | **จ่ายซ้ำ**: เปิดบิลเดียวกันบนเครื่อง A และ B, เปิดหน้าคิดเงินทั้งคู่ แล้วกดยืนยันชำระพร้อมกัน (หรือกดยืนยันรัวๆ) | ใบเสร็จ **1 ใบ** และในรายการบิลมีการชำระ 1 ครั้ง |
| 6 | ประวัติออเดอร์ → **พิมพ์ใบเสร็จ** บิลเดิม | ได้ใบใหม่ (งานใหม่) |
| 7 | **สถานีออฟไลน์**: ถอดสายแลน/ปิด Wi-Fi ของคอมร้าน แล้วกดพิมพ์ QR 2 ใบจากแท็บเล็ต | ไม่ออก POS ขึ้น "โปรแกรมพิมพ์ ... ออฟไลน์" ภายใน ~2 นาที |
| 8 | ต่อเน็ตคืน | 2 ใบออกเอง ภายใน ~30 วินาที แถบแจ้งเตือนหาย |
| 9 | **เครื่องพิมพ์หลุด**: ถอดสาย USB (หรือปิดเครื่องพิมพ์) แล้วกดพิมพ์ QR | ไม่ออก POS ขึ้น "เครื่องพิมพ์ ... ไม่พร้อม" งานรอในคิว |
| 10 | เสียบคืน/เปิดเครื่อง | ใบออกเอง (Windows บางเครื่องรายงานออฟไลน์ช้า ถ้างานไปถึง Windows ก่อน จะขึ้น "ไม่แน่ใจว่าออก" ให้กดพิมพ์ใหม่) |
| 11 | **กระดาษหมด/ถอดสายระหว่างพิมพ์** | งานนั้นขึ้น "ไม่แน่ใจว่าออก" บน POS ไม่พิมพ์ซ้ำเอง กด "พิมพ์ใหม่" ได้ใบใหม่ |
| 12 | **รีสตาร์ทคอม** แล้วล็อกอิน Windows (ไม่เปิดเบราว์เซอร์) | Admin ขึ้นออนไลน์ใน ~1 นาที กดพิมพ์ QR ได้ |
| 13 | Task Manager → End task `node.exe` ของ print-agent | ภายใน ~1 นาที Windows เปิดใหม่เอง (ดู log) |
| 14 | Admin กด **ยกเลิก** โปรแกรมพิมพ์ | ภายใน ~1 นาทีโปรแกรมหยุดรับงาน (log: pairing code rejected) สถานะใน Admin หายไป |

ถ้าข้อไหนไม่ผ่าน ส่งไฟล์ log ล่าสุดจาก `%LOCALAPPDATA%\RanPOS\print-agent\logs` มาด้วย

## สิ่งที่ทดสอบแล้ว / ยังไม่ได้ทดสอบ

ทดสอบแล้ว (อัตโนมัติ, ไม่มีเครื่องจริง):
- `print-agent/test/core.test.js` — ตรรกะของโปรแกรมกับคิวจำลอง: พิมพ์ครั้งเดียว/ตามลำดับ, สองสถานีแย่งงาน,
  เรียกซ้อนกัน, เครื่องพิมพ์ไม่พร้อม → รอ → พิมพ์เมื่อพร้อม, ส่งไม่ถึง Windows → กลับเข้าคิว,
  หลุดระหว่างพิมพ์/ค้าง/โปรแกรมล่ม → uncertain ไม่พิมพ์ซ้ำ, ออฟไลน์ → กลับมาพิมพ์ต่อ,
  รีสตาร์ทกลางงาน → uncertain, heartbeat
- `scripts/printAgent.test.ts` — รหัสเชื่อมต่อ, ตรรกะแถบแจ้งเตือน POS, งานใบเสร็จ
- โค้ดเว็บผ่าน lint/typecheck/build

ยังไม่ได้ทดสอบ (ต้องทดสอบหน้างานตามตารางด้านบน):
- สคริปต์ PowerShell (`ps/*.ps1`, `install/setup.ps1`) บน Windows จริง — ไม่มี Windows ในสภาพแวดล้อมที่พัฒนา
- การพิมพ์จริงกับ Xprinter (ขนาดกระดาษที่กำหนดเอง, การตัดกระดาษ, สถานะออฟไลน์ของ USB ที่ Windows รายงาน)
- Firestore rules ใหม่และทรานแซกชันการชำระเงินกับฐานข้อมูลจริง/emulator
